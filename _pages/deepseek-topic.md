DeepSeek work splits into three tracks, covered separately here: models and the API developers call, the [DeepInfer](/topics/deepinfer/) inference engine, and the DeepSeek Harness agent runtime. We use primary sources (repositories, release notes, model cards, API docs) and only log changes that affect capability, interfaces, deployment, or benchmarks.
