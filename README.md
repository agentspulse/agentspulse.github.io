# AgentsPulse

AgentsPulse 聚焦 AI Agent 研究，提供研究论文综述、架构分析与实践解读。

网站：[https://agentspulse.github.io/](https://agentspulse.github.io/)

## 研究文章

- [Self-Evolving Agents: Model, Harness, and Artifact Evolution](https://agentspulse.github.io/tutorials/self-evolving-agents-review-en/) — 通过 8 篇代表性论文，梳理模型、Harness 与 Artifact 三类自进化路径。
- [Stateful Long-Horizon Agents: 10 Key Papers](https://agentspulse.github.io/tutorials/stateful-long-horizon-agents-review/) — 综述长时程 Agent 的记忆、执行连续性、恢复与延迟行动机制。
- [Measuring Reward-Seeking in RL-Trained Models](https://agentspulse.github.io/tutorials/measuring-reward-seeking-contrastive-beliefs/) — 分析 Contrastive SDF 如何识别模型是在遵循用户意图，还是迎合推测出的评分偏好。
- [When AI Agents Get Internal Access: The Security Boundary Has Changed](https://agentspulse.github.io/tutorials/ai-agent-internal-access-security-boundary/) — 讨论 Agent 获得内部访问权限后的身份、最小权限、隔离和行为监控问题。
- [Coding Agents Enter the FinOps Era: Cost per Successful Task](https://agentspulse.github.io/tutorials/coding-agents-finops-cost-per-successful-task/) — 从成功任务成本、模型路由和确定性验证角度分析 Coding Agent 的经济性。
- [Stateless MCP and the Rise of the Agent Gateway](https://agentspulse.github.io/tutorials/stateless-mcp-agent-gateway/) — 解读无状态 MCP 请求、Agent Gateway、授权、版本管理与可观测性。
- [The Agent Framework Is Not the Runtime: Why Harnesses Are Taking Over Production](https://agentspulse.github.io/tutorials/agent-framework-harness-runtime-production/) — 解析生产级 Agent Harness 如何统一状态、工具边界、控制循环与可观测性。
- [The Model Gateway Is Becoming the Control Plane for Enterprise AI](https://agentspulse.github.io/tutorials/model-gateway-enterprise-ai-control-plane/) — 分析企业模型网关如何整合路由、预算、质量、策略与审计。
- [Agents Enter the Physical World: From VLA Policies to World Action Models](https://agentspulse.github.io/tutorials/physical-agents-world-action-models/) — 梳理具身 Agent 从 VLA 策略走向世界动作模型的架构转变与证据边界。
- [Real-Time Voice Agents Are Distributed Systems](https://agentspulse.github.io/tutorials/real-time-voice-agents-distributed-systems/) — 讨论实时语音 Agent 的传输、流式推理、状态交接与音频评估问题。
